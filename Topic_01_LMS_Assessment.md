# Topic 1 - LMS Assessment
## Setting Up Your API Development Environment

## 1. Assessment Overview

This assessment evaluates your ability to configure a professional API development environment using Postman and n8n, understand client-server communication, execute HTTP GET requests, inspect JSON responses, and validate API interactions using industry-standard tools.

## 2. Assessment Objective

Demonstrate your ability to install and configure Postman and n8n, execute REST API requests, analyze JSON responses, and build a basic API workflow using the HTTP Request node.

## 3. Prerequisites

- Review the Requirement Document.
- Review the Implementation Guide.
- Install Postman.
- Set up a local or cloud n8n instance.
- Have internet access and a GitHub account for submissions.

## 4. Assessment Tasks

- Exercise 1 – Configure Postman and create a personal workspace.
- Exercise 2 – Configure a local or cloud n8n environment.
- Exercise 3 – Execute a GET request against a public REST API using Postman.
- Exercise 4 – Build an n8n workflow with the HTTP Request node and analyze the JSON response.
- Exercise 5 – Record a demo video, upload source code/workflow, and submit all deliverables through the LMS.

## 5. Practical Assessment Checklist

- [ ] Postman installed
- [ ] Workspace created
- [ ] n8n configured
- [ ] HTTP Request node configured
- [ ] GET request executed
- [ ] JSON response analyzed
- [ ] Status code verified
- [ ] Workflow executed successfully
- [ ] Screenshots captured
- [ ] GitHub repository/workflow exported
- [ ] Demo video recorded

## 6. Assessment Success Criteria

- Configure Postman and n8n successfully.
- Execute GET requests correctly.
- Analyze HTTP status codes and JSON responses.
- Build a working n8n HTTP Request workflow.
- Submit all required deliverables.

## 7. Required Deliverables

- Loom/YouTube Demo Video – Mandatory
- GitHub Public Repository or Exported n8n Workflow – Mandatory
- Screenshots of Postman and n8n Execution – Mandatory
- Supporting Documentation (PDF/DOCX) – Mandatory
- Description / Additional Comments – Recommended

## 8. Submission Guidelines

Submit a Loom/YouTube demonstration showing Postman setup, n8n workflow creation, successful GET request execution, JSON response analysis, screenshots, and the exported workflow or GitHub repository. Include any challenges, assumptions, or additional comments.

## 9. Final Submission Checklist

- [ ] Completed all assessment tasks
- [ ] Verified successful API execution
- [ ] Uploaded screenshots
- [ ] Uploaded workflow/GitHub link
- [ ] Uploaded demo video
- [ ] Reviewed all deliverables

## 10. Important Note

Ensure your demo video, workflow or GitHub repository, screenshots, supporting documentation, and additional comments are included before submitting. Incomplete submissions may not be evaluated.
